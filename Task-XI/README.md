# Task XI: Views, Stored Procedures, Functions, and Automation

This folder contains the SQL submission for **DBMS Task XI**.

## File
- [Task-XI.sql](./Task-XI.sql) — standalone MySQL 8.0+ script containing the shared e-commerce schema, sample data, and this task's SQL work.

## Run
1. Open `Task-XI.sql` in MySQL Workbench.
2. Review the setup section before executing. It runs `DROP DATABASE IF EXISTS ecommerce_intelligence` and recreates that database, so do not run it against a database you need to keep.
3. Execute the script and review the result sets/messages for this task.

The SQL is prepared for MySQL 8.0+. Please run it in your MySQL environment to confirm the output.
